四、数据来源与指标解读

数据来源：香港统计处（C&SD）零售销售统计（表号 620-67002 / 620-67003）及访港旅客、CPI 公开数据清洗结果。 本页面采用前端本地 CSV 读取，无后端、无数据库，可直接部署在 GitHub Pages。

核心公式（用于交互测算）： 1) 单价指数 = Value Index / Volume Index 2) 预测价值指数 = 基准年价值指数 × (目标游客量 / 基准年游客量) × (1 + 单价调整率) 3) 缺口% = (预测价值指数 - 2014价值指数) / 2014价值指数
